# 小红书智能发布演示台

这是给客户临时展示用的交互 Demo，前后端都在当前文件夹内。

## 启动方式

双击运行：

```text
start_demo.bat
```

浏览器会打开：

```text
http://127.0.0.1:8787
```

## Demo 能展示什么

- 左侧三大业务板块：智能创作、定时发布、系统配置。
- 上传本地图片或视频。
- 浏览器读取素材尺寸、时长、主色、文件名等信息。
- 填入 DeepSeek Key 后，后端会调用 DeepSeek 生成小红书文案。
- 没有 Key 或接口异常时，会自动返回本地演示文案。
- 支持生成测试素材、编辑标题正文标签、保存定时发布任务预览。

## 文件结构

```text
frontend/index.html      前端单页
backend/server.py        本地后端服务
start_demo.bat           双击启动脚本
```

## 说明

当前 Demo 只做客户可视化演示，不会自动发布到真实小红书账号。
