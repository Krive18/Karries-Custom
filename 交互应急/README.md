# 小红书智能发布工作台

前后端都在当前文件夹内，可用于展示素材解析、AI 文案生成和图文定时发布任务流程。

## 启动方式

双击运行：

```text
启动小红书工作台.bat
```

浏览器会打开：

```text
http://127.0.0.1:8787
```

## 功能范围

- 左侧三大业务板块：智能创作、定时发布、系统配置。
- 上传本地图片或视频。
- 浏览器读取素材尺寸、时长、主色、文件名等信息。
- 可选择 DeepSeek、GPT、豆包、Gemini 等 AI 服务商。
- 填入 API Key 后，后端会按所选服务商处理。
- 没有 Key 或接口异常时，会返回基础文案结果，保证流程可继续。
- 支持编辑标题、正文、标签，并加入图文定时发布任务。

## 文件结构

```text
frontend/index.html      前端单页
backend/server.py        本地后端服务
启动小红书工作台.bat       双击启动脚本
```
