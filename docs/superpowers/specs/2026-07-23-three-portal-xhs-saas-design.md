# 小红书矩阵智能运营平台三端技术设计

## 1. 文档目标

本文档用于沉淀当前主线产品的正式技术设计。项目方向已经从本地桌面工具调整为可部署上线的 Web 产品，目标客户是禾一斯内部运营团队，同时保留点绘环球内部开发者端，用于充值确认、交付处理、自动化运维和系统管理。

本设计优先覆盖正式上线所需的核心闭环：

- 禾一斯员工登录系统，管理小红书矩阵账号。
- 禾一斯员工维护产品知识库和素材。
- AI 根据产品资料、账号定位和运营要求生成小红书内容。
- 人工审核后创建图文或视频发布任务。
- 系统按计划自动提交到小红书定时发布。
- 爆款解析和灵感对话提升选题与脚本质量。
- 智能剪辑先采用工单交付模式，由点绘环球内部处理成片。
- 算力充值采用扫码付款和人工确认到账，形成商业闭环。

## 2. 产品定位

本产品不是桌面端工具，也不是开放给全网注册的公共 SaaS。当前定位是：

> 给禾一斯团队内部使用的小红书矩阵智能运营平台，由点绘环球负责系统搭建、AI 能力、自动化发布能力、算力充值和内部交付支持。

第一版正式上线不再做绿色版、本地安装包或客户电脑本地 MySQL。推荐部署在腾讯云：

- 前端：React Web 应用。
- 后端：FastAPI API 服务。
- 数据库：MySQL 8.0。
- 缓存和任务队列：Redis。
- 文件存储：腾讯云 COS 或同类对象存储。
- 自动化发布：独立浏览器 Worker 节点。
- 反向代理和 HTTPS：Nginx + 腾讯云 SSL。

## 3. 三端划分

### 3.1 用户端

使用对象：禾一斯员工。

员工之间在业务操作上同级，不再拆分团队管理员和普通成员。每个员工都可以维护自己的小红书账号、产品资料、内容任务、灵感对话、爆款解析和充值申请。

用户端核心菜单：

- 工作台：查看今日待发布、账号状态、待审核内容、算力余额、剪辑工单状态。
- 灵感对话：接入 DeepSeek，用于选题、标题、脚本、种草角度和运营策略对话。
- 爆款解析：上传爆款视频或参考素材，后续接入豆包视频理解，拆解钩子、镜头节奏、脚本结构和可复用表达。
- 产品知识库：上传图片、视频、Word、Excel、PDF 等资料，AI 识别产品信息，人工确认后入库。
- 智能创作：基于产品库、账号定位和补充要求生成小红书图文文案。
- 智能剪辑：员工提前上传素材和剪辑脚本，系统生成工单，前台展示智能处理中和预计 24 小时内完成。
- 定时发布：人工审核内容后，选择小红书账号和发布时间，创建自动提交任务。
- 小红书账号：逐个扫码登录账号，维护账号定位、发布频率、可发布时间段和状态。
- 算力中心：查看团队算力余额、发起充值申请、查看个人申请和消耗记录。
- 个人中心：账号资料、密码、安全日志和通知设置。

### 3.2 管理端

使用对象：禾一斯老板和管理层。

管理端是客户侧管理视角，不暴露点绘环球内部处理细节。老板是客户侧超级管理员，管理层由老板授权。

角色建议：

- `client_owner`：禾一斯老板，拥有客户侧最高权限。
- `client_admin`：禾一斯管理层，由老板授权。

管理端核心菜单：

- 经营总览：查看团队账号数、今日任务、发布成功率、待审核内容、剪辑工单、算力余额。
- 员工管理：新增、禁用、重置密码、分配管理权限、查看员工操作情况。
- 小红书账号总览：查看所有员工维护的小红书账号、登录状态、发布频率、风险提示。
- 内容与发布监控：查看图文草稿、审核状态、发布计划、执行日志和失败原因。
- 灵感对话记录：可以查看员工完整对话内容，用于管理选题方向和内容质量。
- 爆款解析记录：可以查看员工提交的视频、解析结果和复用建议。
- 产品知识库总览：查看团队产品资料、AI 识别结果、确认状态和素材库。
- 智能剪辑进度：查看所有剪辑工单状态、提交人、预计完成时间和交付结果。
- 算力与充值：查看团队共享算力余额、员工充值申请、扫码付款入口、充值记录和消耗统计。
- 审计日志：查看关键操作，如删除账号、修改排期、发起充值、确认内容等。

### 3.3 开发者端

使用对象：点绘环球内部管理员、交付人员、运维人员。开发者端不能被禾一斯发现或访问。

角色建议：

- `platform_admin`：点绘环球内部超级管理员。
- `developer_admin`：点绘环球内部交付或运维人员。

开发者端核心菜单：

- 客户管理：查看租户、用户、团队余额、服务状态。
- 充值审核：查看付款申请、付款截图和备注，人工确认到账后给客户团队加算力。
- 充值包配置：配置算力包价格、算力数量、热门标识、启用状态和排序。
- 收款配置：配置客户侧展示的微信或支付宝收款码。
- 智能剪辑工单：查看素材、脚本、剪辑要求、提交时间、预计交付时间，分配剪辑人员并上传成片。
- 自动发布运维：查看 Worker 状态、任务队列、失败截图、人工接管任务。
- AI 服务配置：维护 DeepSeek、豆包等 Provider 的 Key、模型、限流和调用日志。
- 系统审计：查看敏感操作、登录记录、异常任务和后台处理记录。

## 4. 权限和数据隔离

系统采用租户隔离模型。禾一斯作为一个 `tenant`，所有员工、账号、产品、素材、内容、发布计划、算力余额都归属于该租户。

权限原则：

- 禾一斯员工只能看到本租户数据。
- 普通员工可以看到自己创建的内容，也可以按产品需要看到团队共享产品库和团队共享算力余额。
- 禾一斯老板和管理层可以查看本租户完整数据，包括员工灵感对话和爆款解析完整内容。
- 点绘环球开发者端可以按内部权限查看全部租户数据。
- 开发者端入口、菜单、路由和接口权限必须与客户侧隔离。

关键接口必须校验：

- 用户所属租户。
- 用户角色权限。
- 资源所属租户。
- 是否允许查看完整内容。
- 是否允许修改、删除、确认或加算力。

## 5. 算力充值体系

### 5.1 设计原则

客户侧展示统一使用“算力”。后端可以继续使用 `credits` 或 `points` 作为数值计量字段，但所有用户界面、文案和业务记录都以“算力”表达。

第一版不接微信或支付宝支付 API，采用扫码付款 + 人工确认到账：

- 减少支付资质和接口接入成本。
- 方便点绘环球人工控制客户充值。
- 能快速形成收费闭环。
- 后续可以平滑升级为真实支付回调。

### 5.2 团队共享算力钱包

禾一斯使用团队共享算力钱包：

- 一个租户一套团队钱包。
- 所有禾一斯员工消耗同一个团队余额。
- 每次消耗记录到具体员工、模块、任务和时间。
- 老板和管理层能看到员工维度的消耗统计。
- 点绘环球能看到租户维度的充值、消耗和余额。

### 5.3 员工发起充值申请

任何禾一斯员工都可以在用户端发起充值申请。

流程：

1. 员工进入算力中心。
2. 选择充值包或填写期望充值金额。
3. 填写申请原因，例如“本周矩阵发布任务需要增加算力”。
4. 系统创建充值申请，状态为 `pending_manager_review`。
5. 管理端收到申请。

员工只能看到自己发起的充值申请和处理结果。

### 5.4 管理层处理员工申请

老板或管理层在管理端处理员工充值申请。

处理方式：

- 同意并进入付款：状态变为 `pending_payment_confirm`。
- 驳回申请：状态变为 `rejected`，需要填写原因。
- 合并处理：管理层可以把多条员工申请合并为一次团队充值。

付款方式：

- 页面展示点绘环球配置的收款二维码。
- 管理层扫码付款。
- 上传付款截图或填写付款备注。
- 订单进入开发者端待确认。

### 5.5 管理层自主充值

老板或管理层也可以不经过员工申请，直接在管理端自主充值。

流程：

1. 进入算力与充值。
2. 选择充值包。
3. 扫码付款。
4. 上传付款凭证。
5. 进入开发者端待确认。

### 5.6 开发者端确认到账

点绘环球内部人员在开发者端确认充值。

可执行操作：

- 确认到账：给禾一斯团队钱包增加算力。
- 驳回订单：填写原因，不增加算力。
- 标记异常：如金额不符、截图不清晰、重复提交。
- 人工调整算力：支持增加或扣减，并强制记录原因。

所有钱包变动必须写入流水，不能只改余额。

### 5.7 状态机

充值申请状态：

- `pending_manager_review`：待管理层处理。
- `rejected`：管理层已驳回。
- `pending_payment_confirm`：待付款或待提交付款凭证。
- `pending_platform_confirm`：待点绘环球确认到账。
- `credited`：已加算力。
- `payment_exception`：付款异常。
- `cancelled`：已取消。

算力流水类型：

- `recharge`：充值增加。
- `manual_adjust_add`：人工增加。
- `manual_adjust_deduct`：人工扣减。
- `ai_generation`：AI 生成扣费。
- `viral_analysis`：爆款解析扣费。
- `inspiration_chat`：灵感对话扣费。
- `product_extract`：产品资料识别扣费。
- `publish_submit`：自动发布提交扣费。
- `video_edit_order`：智能剪辑工单扣费。
- `refund`：失败退回。

## 6. AI 能力设计

### 6.1 Provider 分工

第一版推荐分工：

- DeepSeek：文本生成、灵感对话、标题正文优化、小红书风格改写。
- 豆包视觉或视频理解：后续用于图片识别、视频解析、爆款拆解。
- 本地解析组件：用于读取 Excel、Word、PDF 的文本和结构化内容。

模型 Key 不写死在前端或代码仓库中，应由环境变量、后台配置或密钥管理服务保存，并在后端调用。

### 6.2 灵感对话

灵感对话不是普通聊天，而是运营助手。

用户端能力：

- 新建对话。
- 选择关联产品、账号定位或发布目标。
- 提问选题、标题、脚本、种草角度、账号矩阵打法。
- 将回答一键转为内容草稿或发布任务素材。

管理端能力：

- 查看员工完整对话内容。
- 按员工、时间、产品、关键词筛选。
- 查看高频问题和 AI 使用量。

开发者端能力：

- 查看调用日志、失败原因、模型耗时和消耗算力。
- 配置系统提示词、模型和限流规则。

### 6.3 爆款解析

爆款解析单独作为菜单，不和灵感对话合并。

用户端能力：

- 上传参考视频或填写参考链接。
- 填写解析目标，例如“拆解钩子”“提取脚本”“参考节奏生成我方脚本”。
- 查看解析结果：前三秒钩子、视频结构、镜头顺序、节奏点、卖点表达、可复用脚本。
- 将解析结果转入智能创作或智能剪辑工单。

管理端能力：

- 查看员工提交的视频和完整解析结果。
- 查看解析产出是否进入后续创作或发布。

边界：

- 不鼓励搬运他人视频。
- 系统只做结构学习、脚本拆解和自有素材重构建议。
- 不提供绕过版权或平台规则的能力。

## 7. 产品知识库

产品知识库是内容生成的数据源。

录入方式：

- 手动填写产品信息。
- 上传产品图片、详情页截图、视频素材。
- 上传 Excel、Word、PDF 等资料。
- 多资料混合上传后由 AI 汇总。

处理流程：

1. 用户上传资料。
2. 系统识别资料类型：图片、视频、文档、表格、PDF。
3. 文件进入对象存储并记录元数据。
4. AI 或本地解析器生成产品信息草稿。
5. 用户确认并修正。
6. 确认后导入产品库。

产品字段：

- 产品名称、品牌、分类、SKU、价格、规格。
- 核心卖点、用户痛点、适用人群、使用场景。
- 材质、成分、颜色、尺码、注意事项。
- 小红书种草角度、常用标签、禁用表达、标题方向。
- 图片素材、视频素材、详情资料和资料来源。

## 8. 智能创作

智能创作负责生成图文内容，第一重点是小红书图文发布。

输入：

- 产品知识库。
- 已选图片或视频素材。
- 小红书账号定位。
- 内容方向。
- 文案语气。
- 补充要求。
- 发布账号和计划发布时间。

输出：

- 标题。
- 正文。
- 标签。
- 卖点摘要。
- 素材使用建议。
- 对应账号。
- 发布检查项。

生成后必须进入人工审核。用户确认后，才允许进入定时发布。

## 9. 智能剪辑工单

自动化剪辑当前不做真实机器剪辑，改为工单式交付。

用户端呈现为“智能剪辑”，实际后台流程：

1. 禾一斯员工提前一天上传素材。
2. 员工填写剪辑脚本、参考风格、时长、字幕、封面和发布时间要求。
3. 系统生成剪辑工单。
4. 用户端展示“待生成视频”“智能剪辑生成中”“预计 24 小时内完成”。
5. 开发者端接收工单。
6. 点绘环球内部安排剪辑人员制作。
7. 开发者端上传成片。
8. 用户端看到已生成视频，可审核后进入定时发布。

工单状态：

- `submitted`：已提交。
- `queued`：排队处理中。
- `in_progress`：智能生成中。
- `internal_editing`：内部制作中。
- `delivered`：已交付。
- `revision_requested`：用户要求修改。
- `cancelled`：已取消。

用户端不展示“人工剪辑人员”等内部信息，只展示智能处理进度和交付结果。开发者端必须展示完整素材、脚本、备注和交付操作。

## 10. 小红书账号和定时发布

定时发布是产品核心能力。

### 10.1 账号管理

禾一斯员工可以逐个扫码登录小红书账号。一个员工可能管理约 20 个账号。

账号信息包括：

- 账号名称、备注、分组。
- 登录状态、最近检测时间。
- 每日发布上限。
- 可发布时间段。
- 最小发布间隔。
- 风险状态。
- 账号定位。
- 常用标签和禁用表达。

### 10.2 定时发布链路

1. 用户选择产品和素材。
2. AI 生成内容。
3. 用户人工审核。
4. 选择发布账号和发布时间。
5. 系统创建发布计划和发布任务。
6. Worker 到时间前领取任务。
7. Worker 打开小红书创作后台。
8. 自动上传素材、填写标题正文标签、选择小红书内置定时发布时间。
9. 提交成功后记录截图、日志和状态。
10. 若失败，进入重试或人工接管。

### 10.3 合规边界

系统只做用户授权后的浏览器自动化操作，不做绕过验证码、绕过风控、批量注册小红书账号或破解平台限制。

遇到以下情况必须转人工：

- 登录态失效。
- 小红书要求验证码。
- 页面结构变化导致自动化失败。
- 上传失败。
- 发布时间不可选。
- 账号风险提醒。
- 平台内容提示异常。

## 11. 管理端能力边界

管理端不仅是权限分配后台，还要让禾一斯老板看清团队运营情况。

应支持：

- 用户管理：员工列表、状态、角色、登录时间、操作统计。
- 权限授权：老板授权管理层。
- 账号监控：查看账号在线状态、发文频率、风险提示。
- 内容监控：查看草稿、审核、发布任务、失败任务。
- AI 内容查看：查看灵感对话和爆款解析完整内容。
- 产品库监控：查看产品资料、素材数量、AI 识别状态。
- 剪辑工单监控：查看工单状态、提交人、预计完成时间、交付结果。
- 算力管理：团队余额、员工申请、扫码充值、消耗统计。
- 审计日志：记录关键管理操作。

## 12. 开发者端能力边界

开发者端是点绘环球内部使用，不对禾一斯暴露。

应支持：

- 租户管理。
- 客户用户查看。
- 团队钱包查看和调整。
- 充值订单确认。
- 充值包和收款码配置。
- 智能剪辑工单接收和交付。
- 自动发布 Worker 监控。
- 失败任务人工接管。
- AI Provider 配置。
- 系统提示词配置。
- AI 调用日志和费用统计。
- 审计日志。

开发者端所有敏感操作必须写审计日志，尤其是加算力、扣算力、查看客户完整内容、修改 AI Key、处理发布失败任务。

## 13. 核心数据模型

以下为逻辑模型，实际 MySQL 设计必须遵循项目数据库规范：表必须有 comment，字段必须有 comment，使用 utf8mb4，合理建立索引，金额和算力变动必须用流水记录。

租户与用户：

- `tenant`：客户团队，如禾一斯。
- `user`：登录用户。
- `user_role` 或用户角色字段：区分员工、老板、管理层、平台管理员、开发者管理员。
- `invite_code`：邀请码。
- `audit_log`：审计日志。

算力充值：

- `team_wallet`：团队共享算力钱包。
- `wallet_ledger`：算力流水。
- `recharge_package`：充值包。
- `recharge_request`：员工或管理层发起的充值申请。
- `payment_proof`：付款截图和付款备注。
- `payment_qr_config`：收款二维码配置。

小红书账号与发布：

- `xhs_account`：小红书账号。
- `xhs_account_profile`：账号定位。
- `content_draft`：内容草稿。
- `matrix_publish_plan`：矩阵发布计划。
- `matrix_publish_item`：单账号发布任务。
- `publish_log`：发布日志。
- `worker_node`：自动化执行节点。
- `manual_takeover`：人工接管记录。

产品和素材：

- `product`：产品主表。
- `product_source_file`：产品资料来源。
- `product_material`：图片、视频、文档等素材。
- `product_extract_job`：产品资料识别任务。
- `ai_extract_record`：AI 识别记录。

AI 能力：

- `inspiration_session`：灵感对话会话。
- `inspiration_message`：灵感对话消息。
- `viral_analysis_job`：爆款解析任务。
- `viral_analysis_result`：爆款解析结果。
- `ai_usage_log`：AI 调用日志和消耗。

智能剪辑：

- `video_edit_job`：剪辑工单。
- `video_edit_material`：工单素材。
- `video_edit_delivery`：交付视频。
- `video_edit_operation_log`：内部处理日志。

## 14. 后端服务分层

建议后端按业务模块拆分，避免把所有逻辑堆到单个 API 文件：

- `auth`：登录、注册、邀请码、令牌。
- `tenant`：租户、用户、角色。
- `wallet`：团队钱包、充值申请、付款凭证、算力流水。
- `xhs_accounts`：小红书账号和账号定位。
- `products`：产品库和素材。
- `ai`：Provider 抽象、调用日志、扣费。
- `inspiration`：灵感对话。
- `viral_analysis`：爆款解析。
- `content`：图文草稿和审核。
- `publish`：发布计划和任务。
- `worker`：自动化 Worker 任务领取、成功、失败、接管。
- `video_edit`：智能剪辑工单。
- `admin`：客户侧管理端接口。
- `developer`：点绘环球内部开发者端接口。

## 15. 前端信息架构

前端建议使用同一个 React 工程，根据登录角色进入不同端：

- `/app/*`：禾一斯用户端。
- `/manager/*`：禾一斯管理端。
- `/developer/*`：点绘环球开发者端。

页面需要做到：

- 用户端偏任务执行和内容生产。
- 管理端偏总览、审核、统计和团队管理。
- 开发者端偏内部交付、财务确认和系统运维。

开发者端入口不能出现在客户侧导航中。

## 16. 扣费策略

所有扣费规则都应配置化，不写死在代码里。

建议第一版可扣费模块：

- 灵感对话：按消息或按会话扣费。
- 爆款解析：按视频解析任务扣费。
- 产品资料识别：按文件或识别任务扣费。
- AI 图文生成：按生成篇数扣费。
- 矩阵批量生成：按账号数量和内容数量扣费。
- 自动发布提交：按发布任务扣费。
- 智能剪辑工单：按工单或按套餐扣费。

扣费失败时，任务不能进入付费执行阶段。失败退回必须通过流水记录，不允许直接修改余额。

## 17. 错误处理和可观测性

必须记录：

- API 错误日志。
- AI 调用日志。
- 算力流水。
- 自动发布截图。
- Worker 任务日志。
- 智能剪辑工单操作日志。
- 开发者端审计日志。

关键异常：

- 算力不足。
- AI Provider 调用失败。
- 文件上传失败。
- 产品识别失败。
- 发布 Worker 离线。
- 小红书登录态失效。
- 充值付款凭证异常。

异常必须对不同角色显示不同信息：

- 用户端显示可理解的处理建议。
- 管理端显示团队影响范围。
- 开发者端显示技术原因、日志和处理入口。

## 18. 当前已有基础和需要调整

根据当前项目状态，已有能力可以继续复用：

- FastAPI 后端结构。
- MySQL 8.0 数据库底座。
- 登录注册、邀请码和积分钱包基础。
- 小红书账号、账号定位、产品库、内容草稿、矩阵发布计划和发布队列基础。
- Worker 任务领取、成功、失败、人工接管接口雏形。
- AI 图文文案链路基础。
- 智能剪辑工单基础。

需要调整：

- Electron 桌面端不再作为主交付形态，前端应向 Web SaaS 方向演进。
- 积分在客户侧统一改名为算力。
- 当前钱包逻辑需要从个人余额升级为团队共享钱包。
- 充值需要补齐员工申请、管理层付款、开发者确认到账。
- 灵感对话和爆款解析需要拆成两个独立菜单和独立数据模型。
- 管理端需要补齐员工管理、完整内容查看、算力统计和运营监控。
- 开发者端需要补齐隐藏入口、充值审核、剪辑工单交付和系统运维。

## 19. 验收标准

上线版主线完成后，应满足：

- 禾一斯员工可以账号密码登录。
- 禾一斯员工可以管理多个小红书账号。
- 禾一斯员工可以填写账号定位。
- 禾一斯员工可以上传产品资料并由 AI 识别，确认后入库。
- 禾一斯员工可以用产品库生成小红书图文。
- 禾一斯员工可以人工审核 AI 内容。
- 禾一斯员工可以创建定时发布任务。
- 系统可以自动提交到小红书内置定时发布。
- 发布任务有状态、日志、截图和异常接管。
- 灵感对话可以正常生成运营建议。
- 爆款解析有独立入口和结果沉淀。
- 智能剪辑工单可以提交、查看进度和接收交付视频。
- 员工可以发起充值申请。
- 老板和管理层可以处理员工充值申请，也可以自主充值。
- 点绘环球开发者端可以确认到账并给团队加算力。
- 管理端可以查看员工、账号、内容、AI 记录、发布任务、剪辑工单和算力消耗。
- 开发者端客户不可见。

## 20. 不在本设计内的事项

以下能力不作为当前主线必须实现：

- 真实全自动 AI 视频剪辑引擎。
- 微信或支付宝支付 API 自动回调。
- 绕过小红书验证码或风控。
- 批量注册小红书账号。
- 搬运他人视频。
- 未经授权下载或二创第三方视频。
- 面向全网开放注册的公开 SaaS 投放。
- Windows 或 macOS 桌面端安装包。
