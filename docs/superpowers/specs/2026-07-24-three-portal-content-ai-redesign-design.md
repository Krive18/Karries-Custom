## 1. 背景

项目由桌面工具方向调整为腾讯云上线的多用户产品。产品服务于禾一斯团队，实际存在三类完全不同的使用者：

1. 禾一斯员工：完成内容创作、产品资料管理、小红书账号管理和定时发布。
2. 禾一斯老板及管理层：管理员工、账号矩阵、内容、发布和算力。
3. 点绘环球内部人员：管理客户租户、AI 配置、充值到账、视频制作工单和系统异常。

当前实现已经具备用户端、开发者端、MySQL 8.0、登录鉴权、爆款解析、灵感对话、视频工单和矩阵发布底座，但仍存在以下产品问题：

- 用户端和管理端目前通过登录后的端切换显示，未形成真正独立的应用边界。
- 智能创作和智能剪辑被拆成两个菜单，用户工作流割裂。
- 灵感对话偏业务表单，不像完整 AI 助手。
- 禾一斯管理端只有概览与部分记录查询，缺少员工、权限、矩阵、充值和日志管理。
- 用户端缺少退出登录，当前令牌仍使用浏览器本地存储，不适合正式上线。
- AI 默认模型仍需迁移到 DeepSeek V4，并且不能向客户暴露底层服务商。

## 2. 目标

### 2.1 产品目标

- 建立用户端、禾一斯管理端、点绘环球开发者端三个独立应用。
- 将智能创作和视频制作合并为一个内容生产入口。
- 将灵感对话升级为名为“小禾”的完整 AI 助手。
- 允许禾一斯管理员新增员工账号，员工无需也不能自行注册。
- 完成从产品资料、内容生产、人工审核、定时发布到结果监控的闭环。
- 完成算力充值申请、到账确认、钱包入账和操作留痕。

### 2.2 技术目标

- 复用已有 MySQL、服务层、发布队列和工单能力，避免推翻重建。
- 三端前端、登录入口、令牌用途和 API 权限严格隔离。
- AI Key 只在开发者端管理，并以密文存储。
- 所有核心表、字段、索引继续遵循 MySQL 8.0 设计规范并包含 `comment`。
- 所有高风险状态变化具有幂等、审计和失败恢复能力。

## 3. 非目标

- 不实现真正的全自动视频剪辑引擎。
- 不承诺 DeepSeek 直接识别图片或视频；视觉识别由后续豆包视觉模型承担。
- 不在用户端或管理端展示 AI 服务商、模型名称、API 地址或 Key。
- 不提供员工公开注册、邀请码注册或自行加入团队。
- 不允许禾一斯管理端访问其他租户数据。
- 不允许用户端发现或访问点绘环球开发者端。

## 4. 已确认的产品决策

1. 采用现有架构增量融合，不重建通用工作流引擎。
2. 智能创作内部使用“图文创作 / 视频创作”两个标签页。
3. 爆款解析在侧边栏排在小禾助手上方。
4. 灵感对话更名为“小禾助手”。
5. 小禾提供“快速回答 / 深度思考”切换。
6. 小禾同时支持产品知识库引用和临时 Word、Excel、PDF 上传。
7. 临时资料解析后可以人工确认并保存到产品知识库。
8. 三个端是三个独立应用、三个独立登录页和三个独立访问地址。
9. 禾一斯老板或管理员可以新增员工。
10. 管理员直接设置员工长期密码。
11. 用户端不提供注册界面，也不开放公共注册 API。

## 5. 三端架构

### 5.1 正式环境

| 应用 | 建议入口 | 登录角色 | 可访问 API |
| --- | --- | --- | --- |
| 禾一斯用户端 | `app.<domain>` | `customer` | `/api/customer/*` 及用户业务 API |
| 禾一斯管理端 | `manage.<domain>` | `client_owner`、`client_admin` | `/api/admin/*` |
| 点绘环球开发者端 | 内部域名或白名单地址 | `developer_admin`、`platform_admin` | `/api/developer/*`、内部设置 API |

三个应用可以共用后端服务和 MySQL 数据库，但不得共用前端路由、导航或登录页面。任何角色不匹配都必须在后端返回 `403`，不能只依赖前端隐藏菜单。

### 5.2 本地开发

| 应用 | 默认端口 |
| --- | --- |
| 用户端 | `127.0.0.1:5175` |
| 管理端 | `127.0.0.1:5176` |
| 开发者端 | `127.0.0.1:5177` |
| 后端 API | `127.0.0.1:8765` |

### 5.3 前端构建

- 用户端、管理端、开发者端使用独立入口组件和独立 Vite 构建模式。
- 三个构建可以共享设计令牌、基础表单、API 错误处理和品牌资源。
- 用户端构建产物不得包含管理端或开发者端页面代码。
- 管理端构建产物不得包含开发者设置和内部工单处理代码。
- 开发者端不在任何客户页面中出现链接或地址提示。

## 6. 认证与员工开通

### 6.1 独立登录

- 用户端登录接口只接受 `customer`。
- 管理端登录接口只接受 `client_owner` 和 `client_admin`。
- 开发者端登录接口只接受内部管理角色。
- 角色不匹配时返回统一的无权限提示，不泄露账号是否存在。

### 6.2 员工创建

禾一斯老板或管理员在管理端创建员工：

1. 输入员工姓名、登录账号、长期密码和启用状态。
2. 后端强制将新账号角色设置为 `customer`。
3. 后端强制使用当前管理者的 `tenant_id`，不接受前端传入任意租户。
4. 创建用户钱包并记录管理员操作日志。
5. 员工立即可以在用户端登录。

管理员可以重置员工密码、停用或重新启用员工。管理员不能修改老板账号、提升员工为老板或跨租户创建用户。只有老板可以授予或取消 `client_admin`。

### 6.3 用户端无注册

- 用户端只显示登录表单。
- 删除注册按钮、注册链接和公开注册说明。
- 公共 `/api/auth/register` 在正式产品表面关闭。
- 员工创建改为受管理端权限保护的 `/api/admin/users`。

### 6.4 正式令牌策略

- 使用 `HttpOnly`、`Secure`、`SameSite` Cookie。
- 访问令牌短有效期，刷新令牌可轮换并支持服务端注销。
- 三个端使用不同的令牌用途或 `audience`。
- 退出登录时服务端吊销刷新会话并清除 Cookie。
- 管理端和开发者端关键操作要求近期登录状态。
- 开发者端增加网络白名单或 VPN 限制。

## 7. 用户端信息架构

侧边栏顺序固定为：

1. 智能创作
2. 爆款解析
3. 小禾助手
4. 产品知识库
5. 定时发布
6. 账号管理

用户端不显示管理端切换、开发者端入口、AI Key、服务商或模型配置。

## 8. 智能创作合并设计

智能创作使用同一页面和两个标签页。

### 8.1 图文创作

流程：

1. 选择产品知识库商品或上传本地图片。
2. 选择小红书账号，加载账号定位、受众、语气和禁用词。
3. 选择内容方向并填写补充要求。
4. AI 生成标题、正文、标签和素材摘要。
5. 用户人工审核并编辑结果。
6. 保存为草稿，或选择发布时间创建发布任务。

生成内容必须可以编辑，未经人工确认不得直接进入发布队列。

### 8.2 视频创作

流程：

1. 选择产品知识库中的视频、图片和产品资料，或上传临时素材。
2. 填写剪辑脚本、镜头要求、节奏、字幕和补充说明。
3. 提交视频制作任务。
4. 用户端显示“智能处理中，预计 24 小时内完成”以及任务状态。
5. 点绘环球开发者端下载素材并安排剪辑。
6. 完成后上传成片，用户端显示交付文件。
7. 用户人工确认成片，补充标题和正文后创建视频发布任务。

视频任务状态至少包括：待处理、处理中、待补充、已交付、已关闭。状态转换必须由服务端校验。

### 8.3 共享数据

图文创作和视频创作共享：

- 产品资料
- 素材
- 小红书账号定位
- 内容草稿
- 定时发布任务
- 算力与操作记录

侧边栏不再保留单独的“智能剪辑”菜单。

## 9. 小禾助手

### 9.1 界面结构

- 左侧：新建对话、搜索和历史会话。
- 中间：小禾消息流、附件、引用来源和消息输入框。
- 顶部：快速回答、深度思考和提取产品变量。
- 右侧使用可折叠上下文抽屉，不长期占用主对话宽度。

所有助手消息统一显示“小禾”，不显示 DeepSeek、模型名或供应商。

### 9.2 对话能力

- 多轮连续对话
- 流式输出
- 快速回答
- 深度思考
- 产品知识库引用
- 小红书账号定位引用
- Word、Excel、PDF 文本解析
- 产品变量提取
- 保存为内容草稿
- 转入智能创作
- 临时资料保存到产品知识库

深度思考只展示“正在思考”状态和最终结果，不展示或持久化底层原始推理内容。

### 9.3 模型策略

默认配置：

- 快速回答：`deepseek-v4-flash`，关闭思考模式。
- 深度思考：`deepseek-v4-pro`，启用思考模式。

具体模型允许开发者端修改。客户侧只看到“小禾”的模式名称。

### 9.4 附件与产品变量

附件流程：

1. 校验扩展名、MIME、大小和文件签名。
2. 将原文件存入租户隔离的对象存储路径。
3. Word、Excel、PDF 通过受控解析器提取文本。
4. 对超长文本切分并建立会话上下文。
5. 小禾基于解析文本回答。
6. 用户点击“提取产品变量”后生成结构化产品草稿。
7. 用户确认修改后保存到产品知识库。

DeepSeek 文本接口不直接承担图片和视频识别。图片和视频在接入豆包视觉模型后，将识别结果作为文本上下文交给小禾。

### 9.5 工具调用

小禾的工具调用由服务端白名单控制，首批工具包括：

- 查询当前用户的产品知识库
- 查询当前用户的小红书账号定位
- 提取产品变量
- 创建内容草稿
- 转入智能创作

模型生成的工具参数必须经过 Pydantic 校验和租户权限校验，不能直接执行任意数据库或网络操作。

## 10. 禾一斯管理端

### 10.1 运营总览

- 团队成员数
- 小红书账号数
- 今日、本周发布量
- 待审核、待发布、发布失败任务
- 小禾与爆款解析算力消耗
- 视频任务处理状态

### 10.2 成员与权限

- 新增员工
- 编辑员工姓名和状态
- 设置或重置员工长期密码
- 停用、启用员工
- 查看最后登录时间
- 老板授予或取消管理员

### 10.3 账号矩阵

- 查看当前租户全部小红书账号
- 按员工、账号定位和登录状态筛选
- 查看发布频率、最近发布时间和失败情况
- 显示登录失效、频率异常和连续失败提醒

### 10.4 内容与 AI 记录

- 查看小禾完整对话
- 查看爆款解析任务和结果
- 查看图文草稿与视频制作任务
- 按员工、产品、账号、时间和状态筛选
- 对待审核内容进行通过或退回

### 10.5 发布监控

- 查看全团队定时发布任务
- 展示待审核、待发布、执行中、成功、失败和人工接管
- 支持重试、取消和查看失败原因
- 所有跨员工查询按当前租户过滤

### 10.6 产品资料

- 查看团队产品知识库
- 检查产品参数、卖点和素材完整度
- 管理共享产品
- 查看产品关联的草稿和发布任务

### 10.7 视频任务

- 查看员工提交的视频任务
- 查看素材、脚本和补充要求
- 催办或退回补充资料
- 查看交付状态

### 10.8 算力与充值

- 查看团队总算力和成员消耗
- 员工提交充值申请
- 老板或管理员发起充值
- 老板分配团队算力给员工
- 查看充值状态和钱包流水

### 10.9 操作日志

记录成员、权限、密码重置、充值、审核、发布重试和算力分配操作。日志包含操作者、租户、对象、动作、结果、时间和必要的非敏感摘要。

## 11. 点绘环球开发者端

- 租户管理
- AI Key 与模型配置
- AI 调用和费用记录
- 充值申请与到账确认
- 视频制作工单处理
- 发布异常和人工接管
- 系统运行状态
- 内部操作审计

开发者端可以查看跨租户数据，但所有读取和变更必须记录内部审计日志。

## 12. AI Key 与供应商隐藏

- API Key 只允许开发者端配置。
- Key 使用现有密钥加密服务写入 `system_setting`。
- 加密主密钥仅存在于腾讯云环境变量或密钥管理服务。
- API 返回 `has_key` 和脱敏状态，不返回完整 Key。
- 异常、日志、测试快照和前端构建产物不得包含 Key。
- 用户端和管理端只显示“小禾可用”或“服务暂时不可用”。
- 允许开发者端更换 Key、停用某个模式和调整模型。

## 13. 爆款解析

- 侧边栏位于小禾助手上方。
- 用户上传参考视频、链接或文字观察。
- 当前阶段使用已有分析任务结构。
- 接入豆包视觉 API 后，视频抽帧、语音转写和镜头分析进入视觉服务。
- 结构化分析结果可以转入小禾继续讨论，也可以保存为内容草稿。
- 用户端不显示豆包或其他供应商名称。

## 14. 定时发布

主流程保持：

1. AI 生成内容。
2. 用户人工审核并确认。
3. 创建定时发布任务。
4. 发布 Worker 在计划时间领取任务。
5. Worker 使用对应小红书账号登录状态执行发布。
6. 回写成功、失败或人工接管状态。

图文与视频使用同一发布任务体系，但必须校验素材类型。发布任务必须具备幂等键、领取租约、重试次数、失败原因和操作日志。

## 15. 充值与算力

流程：

1. 员工、老板或管理员创建充值申请。
2. 系统生成充值单并显示点绘环球收款二维码。
3. 用户完成线下扫码支付。
4. 充值单进入“待确认”状态。
5. 点绘环球开发者端核对到账。
6. 服务端通过事务增加钱包余额并写入钱包流水。
7. 三端同步显示充值结果。

到账确认必须幂等，不能因重复点击重复入账。充值单状态至少包括待支付、待确认、已到账、已取消和已驳回。

## 16. 数据模型调整

实施阶段需要评估并新增或扩展以下数据：

- 用户刷新会话和令牌吊销记录
- 员工状态、最后登录信息和密码重置审计
- 小禾会话模式
- 小禾附件和解析状态
- 产品变量提取草稿
- 充值订单
- 团队算力分配流水
- 内容审核记录
- 管理端和开发者端操作日志

所有新增表必须包含：

- 主键
- 租户或平台作用域
- 状态字段及中文 `comment`
- `create_time`、`update_time`
- 业务唯一键或幂等键
- 常用筛选条件的联合索引
- 软删除或状态停用策略

不得使用无注释字段，不得使用外键级联删除核心业务记录。

## 17. API 边界

### 17.1 用户端

- 登录、退出和当前用户
- 我的产品、素材、账号、草稿和发布任务
- 小禾会话和附件
- 爆款解析
- 视频制作任务
- 我的钱包、流水和充值申请

### 17.2 管理端

- 管理端登录和退出
- 当前租户成员与权限
- 当前租户账号矩阵
- 当前租户内容、AI、发布和视频记录
- 当前租户充值、算力和操作日志

### 17.3 开发者端

- 内部登录和退出
- 跨租户管理
- AI 配置
- 充值到账
- 视频工单处理
- 发布异常接管
- 系统监控和内部审计

所有列表接口使用统一分页，并明确租户过滤、排序和筛选字段。

## 18. 错误处理

- 登录失败使用统一中文提示，不返回原始技术错误。
- 角色错误返回 `403`，并清除不适用于当前端的登录状态。
- AI 未配置、余额不足、超时和供应商故障使用稳定业务错误码。
- 文件解析失败保留原文件和失败原因，允许重新解析。
- 视频任务和发布任务状态冲突返回可解释错误，不静默覆盖。
- 充值重复确认返回原结果，不重复入账。
- 前端显示用户可执行的下一步，原始异常仅进入服务端日志。

## 19. 安全要求

- 密码使用强哈希算法，不可逆存储。
- 管理员设置密码时执行最小长度和复杂度校验。
- 登录、员工创建、密码重置和充值接口限流。
- 文件上传执行大小、类型、签名和路径校验。
- 对象存储按租户和用户隔离。
- 管理端和开发者端写操作执行 CSRF 防护。
- 用户输入进入 AI 前做长度和敏感数据控制。
- 工具调用参数执行结构验证和权限校验。
- 所有 SQL 使用参数化查询。
- 不在客户端、日志、数据库明文或 Git 中保存 API Key。

### 20.1 后端

- 管理员创建员工并成功登录用户端
- 管理员不能跨租户创建或查看员工
- 老板和管理员权限边界
- 小禾快速与深度模式
- 附件解析、产品变量确认与保存

- 发布任务幂等和租约
- 充值确认幂等和钱包事务
- AI Key 加密与脱敏

### 20.2 前端

- 三个独立登录页
- 用户端不出现注册、管理或开发者入口
- 管理端拒绝员工账号
- 开发者端拒绝客户账号
- 智能创作双标签工作流
- 爆款解析导航顺序
- 小禾会话、模式切换、附件和草稿转换

- 员工完成图文创作并创建定时发布任务

- 用户、管理者和开发者分别只能看到允许的数据

## 21. 迁移顺序

1. 拆分用户端、管理端、开发者端入口和登录。
2. 增加管理端员工账号管理。
3. 合并智能创作和视频创作导航与页面。
4. 升级小禾界面和 DeepSeek V4 适配。
5. 增加附件解析与产品变量沉淀。
6. 补齐管理端矩阵、内容、发布和产品模块。
7. 补齐充值与算力流程。
8. 加固 Cookie、令牌、审计、限流和腾讯云部署配置。

每个阶段必须保持已有后端测试通过，并补充对应的 MySQL 集成测试和前端行为测试。

## 22. 验收标准

- 三个端使用独立地址和独立登录页。
- 用户端没有注册界面或管理端切换。
- 管理员新增的员工可以立即登录用户端。
- 智能创作只有一个侧边栏入口，并提供图文和视频两个标签。
- 爆款解析位于小禾助手上方。
- 小禾支持快速回答、深度思考、产品库、附件和草稿转换。
- 客户侧不出现 DeepSeek、豆包、模型名、API 地址或 Key。
- 禾一斯管理端具备员工、权限、矩阵、内容、发布、产品、视频、算力和日志模块。
- 点绘环球开发者端可以处理 AI 配置、充值、视频工单和异常任务。
- 所有数据按租户隔离，关键操作有审计记录。
- 充值、发布和 AI 任务具有幂等与失败恢复能力。

## 23. 备选方案与取舍

### 仅前端合并

开发较快，但业务记录和状态仍然割裂，不适合作为正式产品，已否决。

### 重建通用工作流引擎

扩展性高，但会推翻大量已有能力并显著延长周期，当前不采用。

### 增量融合现有架构

保留已有数据库、服务和队列，按清晰边界逐步拆分三端并补齐能力。风险和交付质量更可控，已确认采用。
