# AI 对话多模板与普通模式设计

## 目标

- 普通模式使用通用大语言模型提示词，不自动引入小红书、产品、创作上下文或个性化角色。
- 用户可以持久化维护多个个性化模板，并在普通模式和任一模板之间快速切换。
- 会话创建时绑定当前对话空间；历史会话按普通模式或模板隔离展示。
- 新建会话和创作上下文改为弹窗，释放主对话区域宽度，不改变现有视觉语言。

## 数据模型

- 新增 `ai_personalization_template`：按租户和用户保存模板名称、助手名称、角色特征、称呼、职业、用户资料、回答偏好和状态。
- 新增 `ai_chat_preference`：保存用户最后选择的模式及模板。
- `inspiration_session` 新增 `personalization_template_id`；普通会话固定为 `0`，个性化会话绑定模板 ID。
- 删除模板采用归档，已有会话仍保留模板快照关联和历史数据。

## 接口

- 模板列表、创建、更新、复制和归档均位于 `/api/inspiration/personalization/templates`。
- `/api/inspiration/personalization/preference` 读取和保存最后选择。
- 会话列表接受 `interaction_mode` 与 `personalization_template_id`，后端执行归属过滤。
- 保留旧的单模板接口作为兼容层，避免破坏已有调用。

## 对话行为

- 普通模式的系统提示词只定义通用助手行为；身份问答也返回通用助手身份。
- 个性化模式读取会话绑定的模板，而不是读取一个全局可变档案。
- 普通模式隐藏“保存为内容草稿”和“用于视频创作”等业务动作。

## 前端交互

- 输入区提供对话空间下拉框：普通对话、已有模板、管理模板。
- 切换空间后重新加载该空间的会话，并优先打开该空间最近一次使用的会话。
- 模板管理弹窗支持新增、编辑、复制和归档。
- 新建会话弹窗继承当前空间；创作上下文通过独立弹窗查看。

## 兼容与安全

- 迁移只新增表和字段，不重置现有数据。
- 旧个性化档案在首次读取模板列表时迁移为“默认个性化模板”。
- API 始终校验模板归属，禁止跨租户或跨用户绑定。
